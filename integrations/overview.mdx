Alfred Black reaches the outside world through three layers: **sidecars** that live in the compose stack and ship their own UI; **Composio**, the external surface for roughly every other third-party app; and **MCP clients** — the way Claude Desktop, Claude Code, and claude.ai itself talk to Alfred.

The three layers are independent. A fresh install boots with all four sidecars enabled by default *(docker-compose.yaml:643–1245)*; Composio activates the moment you fill `COMPOSIO_API_KEY` in `.env`; MCP clients work as soon as `mcp.{$DOMAIN}` resolves and you copy the per-app URL out of `/settings#agent`.

## Three layers, one mental model

A **sidecar** is a container (or a cluster of containers) the compose stack runs alongside Alfred itself. Each sidecar exposes its own web UI at a subdomain, has its own database, and is reached by Hermes through an MCP app — `plane`, `sure`, or `vaultwarden` *(packages/mcp-server/src/tools/registry.ts:37–44)*. They are full applications in their own right; Alfred just happens to host and orchestrate them.

**Composio** is the opposite shape — one tool over many remote apps. There is no Composio container; ctrl-api holds your `COMPOSIO_API_KEY`, and the `execute` MCP app proxies a single `composio_execute(action, args)` call out to Composio's hosted platform *(packages/mcp-server/src/tools/execute.ts:64–81)*. Every third-party app Composio supports — Gmail, GitHub, Slack, Notion, and a thousand more — is reached this way, with the action name as a parameter.

**MCP clients** are how the outside model layer talks back. Hermes registers six MCP servers per profile — five stdio apps plus one HTTP proxy *(packages/hermes/hermes-config.yaml.njk:285–354)*. The MCP catalogue lists a sixth stdio app (`hermes`) that is not yet wired into the profile template; the five stdio apps plus the HTTP `alfred-ctrl` proxy are served externally at `mcp.{$DOMAIN}/<app>/mcp` for claude.ai, Claude Desktop, and Claude Code *(packages/mcp-server/src/index.ts:96–106, 244–334)*. Across all of them you can reach roughly 178 distinct tools.

<Note>
The headline counts after the 2026-05-29 wave: **5 sidecars** (Plane, Sure, Vaultwarden, Paperclip, optional Tailscale), **7 stdio MCP apps + 1 HTTP `alfred-ctrl` proxy** registered per Hermes profile (the original five plus `paperclip`, `hass`, `files` — and the `hermes` catalogue app remains opt-in), and **~28 containers** total *(docker-compose.yaml)* now that Vexa's nine containers are gone. The optional Tailscale profile adds one more.
</Note>
