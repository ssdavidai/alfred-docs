claude.ai exposes two text surfaces an MCP connector can populate: **Custom Skills** (per-tool markdown files that document calling conventions) and **Personalisation** (the profile-level instructions block). Alfred ships canonical content for both. None of it is required — the MCP tools work without a single skill installed — but each file is a heavy productivity multiplier for the model.

This page documents what Alfred ships, where it lives in source, and how to install it.

## What ships

Six markdown files plus one custom-instructions document *(packages/mcp-server/skills/ and packages/mcp-server/instructions/)*:

| File | Source | Purpose |
|---|---|---|
| `alfred-mcp-skill.md` | `packages/mcp-server/skills/` | Operator's manual for the `alfred` MCP app — vault read/write, agent delegation, workflow orchestration, OpenClaw diagnostics. |
| `sure-mcp-skill.md` | `packages/mcp-server/skills/` | Sure operator's manual — transactions, accounts, budgets, holdings, clustering. |
| `plane-mcp-skill.md` | `packages/mcp-server/skills/` | Plane operator's manual — issue read/write, search, project metadata. |
| `vaultwarden-mcp-skill.md` | `packages/mcp-server/skills/` | Vaultwarden operator's manual — items, folders, password generation, rotation propagation. |
| `execute-mcp-skill.md` | `packages/mcp-server/skills/` | Composio operator's manual — `composio_execute`, discovery, connection management. |
| `alfred-composio-<toolkit>.md` | Auto-generated per connected toolkit | Per-toolkit canonical payloads (Gmail, Slack, GitHub, …). Generated by ctrl-api's integrations route when a connection lands `ACTIVE`. |
| `alfred-custom-instructions.md` | `packages/mcp-server/instructions/` | The Personalisation block — identity transfer ("You are Alfred"), tone, operating discipline. |

The web app vendors these files into `packages/web/public/mcp-skills/` *(packages/ctrl/src/api/routes/claudeSetup.ts:162–166)* so the dashboard can serve them as direct downloads from `/settings#agent`. The canonical source of truth stays in `packages/mcp-server/`; CI keeps the vendored copies in sync.

The `hermes` MCP app (the sixth app in the bundle, added 2026-05-26) does not yet ship a dedicated skill file — its 7 tools are simple enough that tool descriptions alone suffice in practice.

## Where it goes in claude.ai

claude.ai treats the two surfaces differently:

### Custom Skills (per-MCP-app)

claude.ai's **Custom Skills** feature lets you attach markdown files to a specific connector. The model loads the skill content as system context whenever it routes a call through that connector.

<Steps>
  <Step title="Open Settings">
    In claude.ai, go to **Settings → Connectors**.
  </Step>
  <Step title="Pick a connector">
    Click the connector you wired up earlier (`Alfred`, `Sure`, `Plane`, `Vaultwarden`, `Execute`). Each has its own skill surface.
  </Step>
  <Step title="Upload the skill">
    Click **Add skill**. Upload the matching markdown file (download from `/settings#agent` on the dashboard, or grab the file directly from `packages/mcp-server/skills/`).
  </Step>
  <Step title="Repeat per connector">
    Each connector gets its own skill. Composio's auto-generated `alfred-composio-<toolkit>` files attach to the `Execute` connector — one per toolkit.
  </Step>
</Steps>

### Personalisation (profile-level)

`alfred-custom-instructions.md` goes in claude.ai's **Personalisation** field (Settings → Profile → "What personal preferences should Claude consider in responses?"). Paste everything from `You are Alfred` through the end *(packages/mcp-server/instructions/alfred-custom-instructions.md:1–3)* — the header lines that explain where to paste are intentionally above the paste boundary.

This is the file that turns claude.ai *into* Alfred for this account — establishing the principal model ("Sir"), the tone register (warm + dry, never sycophantic), and the operating discipline (anticipate, be brief, push back when something seems wrong, never fabricate).

## The Claude Code skill

Claude Code's skill surface is filesystem-based: skills live in `~/.claude/skills/` (user-scoped) or `.claude/skills/` (project-scoped). To install Alfred's catalogue:

```sh
mkdir -p ~/.claude/skills
git clone https://github.com/ssdavidai/alfred /tmp/alfred-src
cp /tmp/alfred-src/packages/mcp-server/skills/*.md ~/.claude/skills/
```

The skill files are auto-loaded the next time Claude Code starts. The Personalisation document is not consumed by Claude Code in the same way — its closest analog is `~/.claude/CLAUDE.md` at the user level. If you want Alfred-the-butler tone from Claude Code, paste the body of `alfred-custom-instructions.md` into your user `CLAUDE.md`.

## Updating

The canonical skills evolve in lockstep with the MCP catalogue — when a tool's contract changes, the skill changes with it. Re-download from `/settings#agent` after major releases, or pull from `packages/mcp-server/skills/` if you cloned the repo. The Composio skills under `alfred-composio-<toolkit>` regenerate automatically when their toolkit's actions change upstream.
