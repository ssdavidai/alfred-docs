Alfred Black is mostly orchestration. The hard work — the inference runtime,
the dashboard framework, the workflow engine, the integrations — comes from
the projects below. Deep thanks to their authors and maintainers.

## Runtime and intelligence

- **[Hermes Agent](https://github.com/NousResearch/hermes-agent)** by
 [NousResearch](https://nousresearch.com). The AI runtime that powers
 Alfred. Hermes runs three supervised profiles (`main`, `workers`, `heavy`)
 inside one Docker image, speaks the OpenAI Responses API natively, and
 hosts the MCP servers that give Alfred its tools. The `hermes-lcm`
 cross-session memory plugin and the `one-alfred` continuity plugin live
 inside this runtime.
- **[Temporal](https://temporal.io)**. The durable workflow engine that
 drives the intelligence layer in `packages/learn` — 30+ workflows
 including `EventProcessor`, `SignalExtract`, `SignalRouter`,
 `DecisionRouter`, `Reflection`, `Briefing`. Temporal's replay model is
 what makes Alfred's reasoning survive restarts and rollouts.
- **[Composio](https://composio.dev)**. The integrations layer that gives
 the principal one-click access to ~1,000 third-party apps via the
 `execute` MCP server. Composio handles OAuth, scope management, and the
 recurring poll machinery.
- **[Ollama](https://ollama.com)** with the `nomic-embed-text` model.
 Local embeddings for the vault's `sqlite-vec` semantic layer, so Alfred's
 recall never needs to talk to a paid embedding API.

## Dashboard and surfaces

- **[Wasp](https://wasp-lang.dev)**. The full-stack framework powering the
 Alfred Black dashboard — auth, ORM, queries, actions, jobs, routes — all
 declared in `main.wasp` and compiled to a Node/React stack.
- **[Caddy](https://caddyserver.com)**. The reverse proxy that handles
 ingress for all seven Alfred Black hostnames (`{$DOMAIN}`, `api.`,
 `plane.`, `sure.`, `vault.`, `mcp.`, `sms.`, `voice.`) and issues TLS
 certificates via Let's Encrypt HTTP-01 with zero configuration.
- **[Let's Encrypt](https://letsencrypt.org)** for the certificates Caddy
 provisions.

## Sidecars (the principal-facing surfaces)

- **[Plane](https://plane.so)** — the open-source project management app
 that backs `/matters` for principals who like a Linear-style view of their
 work. Eleven sub-services (`plane-api`, `plane-worker`, `plane-beat`,
 `plane-web`, `plane-space`, `plane-admin`, `plane-live`, `plane-proxy`,
 `plane-db`, `plane-redis`, `plane-mq`, `plane-minio`).
- **[Sure](https://github.com/we-promise/sure)** — the open-source personal
 finance app that backs `/finances` (via 116 tools exposed through the
 `sure` MCP server).
- **[Vaultwarden](https://github.com/dani-garcia/vaultwarden)** — the
 Bitwarden-compatible secrets manager. Alfred Black uses it as the
 principal's personal password vault, exposed at `vault.{$DOMAIN}`.

## Optional capabilities

- **[Recall.ai](https://recall.ai)** — hosted meeting bot that joins Zoom /
 Google Meet / Microsoft Teams / Cisco Webex calls, streams transcript via
 webhook, and supports outbound audio so Alfred can speak in meetings.
 Replaced the retired self-hosted Vexa stack in PR #126; see
 [Recall.ai](/integrations/recall).
- **[Twilio](https://twilio.com)** — programmable voice + SMS. Alfred Black's
 voice channel uses Twilio Media Streams bridged to OpenAI's `gpt-realtime`
 endpoint via `voice-bridge`.
- **[OMI](https://omi.me)** — the always-on wearable that streams ambient
 audio into Alfred's `/channels` OMI card.

## Historical

- **[Vexa](https://github.com/Vexa-ai/vexa)** — the nine-container
 self-hosted meeting bot that shipped through 2026-05-29. Retired in PR #126
 and replaced by Recall.ai.

## Storage

- **[SQLite](https://sqlite.org)** with the
 **[sqlite-vec](https://github.com/asg017/sqlite-vec)** extension. Three of
 Alfred's four stores (`alfred-state.db`, `cold.db`, `ingest.db`) are
 SQLite. The vector layer for semantic recall is `sqlite-vec`.
- **[PostgreSQL](https://postgresql.org)** — used by the dashboard
 (`web-db`), Plane (`plane-db`), and Sure (`sure-db`).
