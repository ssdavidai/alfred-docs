The `sure` app is by far the largest tool surface in the catalogue: 95 tools covering the full domain model of the self-hosted [Sure](https://github.com/we-promise/sure) personal-finance application. The taxonomy below mirrors Sure's internal model — accounts, transactions, categories, merchants, tags, rules, transfers, holdings, valuations, budgets, recurring, imports, sharing, administration.

**Backend.** Every tool routes through `proxyToCtrl()` to ctrl-api's `/api/v1/sure/*` *(packages/mcp-server/src/tools/sure.ts:1-19)*. ctrl-api fronts the self-hosted Sure Rails app on `sure-web:3000` using two paths: **REST** for query endpoints, and **Rails-runner** — a sandboxed `bin/rails runner` shell-out — for mutations Sure's REST API does not expose. Both go through the same MCP call. Bearer auth uses `AAS_API_KEY`; ctrl-api holds the Sure API key seeded by `sure-init`.
