## What it is

Alfred Black is a single-VM AI butler stack: one repository, one
`docker compose up`, one stack. You bring a Linux VM, a domain name, and a couple of
API keys; the bootstrap script handles the rest.

Once running, a user with a Linux VM can:

```sh
git clone https://github.com/ssdavidai/alfred.git
cd alfred && cp .env.example .env   # fill DOMAIN, ACME_EMAIL, owner, API keys
./scripts/bootstrap.sh              # generates secrets, validates env
docker compose up -d
```

…and have a working Alfred at `https://<their-domain>` with TLS, the dashboard,
and the full intelligence layer.

## What's in the box

- **A daily decision queue** (the Desk) with an audit ledger — every decision you take, recorded.
- **A daily brief** in plain prose, composed at 06:00 local from the matters on your plate.
- **A Markdown vault** with twelve canonical record types — readable in Obsidian, written by Alfred.
- **An intelligence layer** that learns from your decisions and promotes hunches into autonomous actions over time.
- **A connections catalogue** that exposes ~165 tools across Gmail, Calendar, Drive, Plane, Sure, Vaultwarden, and the Composio surface (every connected third-party app) to Alfred — and to Claude Desktop or Claude Code via MCP.
